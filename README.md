## Objetivo

Encontrar, usando Programação Genética, a função que converte Celsius (C) em Fahrenheit (F), sem informar a fórmula ao algoritmo.

As fórmulas conhecidas, que serão usadas apenas para gerar os dados e conferir o resultado, são:

- Celsius para Fahrenheit: `F = C × 9/5 + 32`
- Fahrenheit para Celsius: `C = (F − 32) × 5/9`

## O que é Programação Genética?

Técnica inspirada na evolução natural. Uma população de expressões matemáticas evolui ao longo de gerações por meio de seleção, cruzamento e mutação, até que alguma delas se aproxime da solução.
